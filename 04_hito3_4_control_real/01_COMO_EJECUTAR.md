# Cómo ejecutar Hitos 3 y 4

En Ubuntu, entra a `04_hito3_4_control_real/02_vevas_studio`, ejecuta `python3 -m venv .venv`, luego `.venv/bin/python -m pip install -r requirements.txt` y `bash iniciar_simulacion.sh`. Abre [VEVAS Studio](http://localhost:9012/). Para sesiones con el brazo, consulta la [guía de operación](01_docs/03_guias/01_GUIA_COMPLETA_HITO3_4.md).
