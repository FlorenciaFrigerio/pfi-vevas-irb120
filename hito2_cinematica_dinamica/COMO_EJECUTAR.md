# Cómo ejecutar Hito 2

Desde la raíz, instala NumPy con `python -m pip install numpy` y ejecuta `python ros2_irb120_description/scripts/demo_recorrido.py --seguido`. El [notebook](notebooks/Hito2_VEVAS.ipynb) reúne los cálculos. Para gráficos, instala Matplotlib. Consulta el [manual](01_docs/03_guias/01_MANUAL_HITO2.md).
